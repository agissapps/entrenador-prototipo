# Diario de Tiro · Entrenador (prototipo)

Prototipo de la página web para entrenadores de arquería que se conecta con la app
Diario de Tiro. **Todos los datos son inventados**: nada se guarda ni se conecta con la app todavía.

Verla en línea: https://agissapps.github.io/entrenador-prototipo/

## Correrla en la computadora

```bash
npm install
npm run dev
```

Se publica sola en GitHub Pages cada vez que se sube un cambio a `main`.
